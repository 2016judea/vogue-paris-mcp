Privacy

Last updated November 20, 2026. Brick and Mortar AI LLC, Saint Paul, Minnesota.

No account, nothing stored

The connector needs no sign-in. It receives only what the assistant sends it: a year, a date range, an issue date or page numbers. It does not receive your conversation, and it keeps nothing.

What is counted

Each tool call sends one anonymous event to PostHog: which tool, whether it worked, how long it took, the year asked about, how many issues and images came back, and which app made the call (Claude, ChatGPT and so on, read from the user agent). Each event gets a random ID, so calls can't be linked to each other or to a person. No IP address is stored with it.

These pages use Vercel Web Analytics, which counts visits without cookies.

Where the images come from

Covers and pages are scans from Gallica, the Bibliothèque nationale de France's digital library, served from vogue-paris.vercel.app. Images are returned only for issues in the US public domain. Later issues get a link instead.
